# 多语言与共享 UI：第二阶段验收

日期：2026-10-24。范围：本地前端实现和验证，尚未发布桌面安装包。

后续真实 macOS WebView、PostgreSQL/MySQL 业务流程验收及修复记录见 [原生桌面验收](LOCALIZATION_NATIVE_ACCEPTANCE.md)，其中明确列出已通过项目、缩放修复及未覆盖的平台和服务边界。

## 已接入的业务界面

| 模块 | 本阶段覆盖 |
| --- | --- |
| 数据源 | 数据库选择、连接管理、连接创建/编辑、TLS/SSH 字段、测试阶段与结果、删除确认、DDL 导入预览 |
| 对象树 | 表/视图/枚举分类、搜索、对象菜单、视图定义、枚举值与使用位置 |
| 详情面板 | 结构、字段/索引/约束、团队知识表单、业务分组、知识确认、Git/迁移证据、AI 解释和请求预览的界面文案 |
| 画布 | 表节点提示、画布工具、缩放、小地图、布局/撤销/固定、选择、保存视图、图表导出操作 |
| 关系 | 逻辑关系管理、字段映射、基数、状态、创建/编辑/删除、推断候选、逐条与批量审查、批处理历史 |
| 查询 | SQL 编辑器、执行控制、输出标签、结果表格/图表、字段分析、导出对话框、查询历史、AI 草稿上下文与请求审查 |
| 历史/变更 | 快照列表、比较方向、版本选择、变更筛选、前后属性、比较图例、空状态；结构预检和报告导出界面 |

所有新增界面文案使用同一个 `useI18n` / `Translate` 入口。词典新增 `business`、`businessSupport`、`businessMeta`、`businessExtra`、`queryContext`、`queryResult`、`queryErrors` 和 `queryEditor` 命名空间。中英键集合与插值参数一致性继续由基础测试检查。

`i18n/business-labels.ts` 仅允许映射明确的应用元数据，例如关系基数、状态、布局操作、快照属性标签和本地结果分析说明。它不是对任意英文文本的自动翻译器。业务标识、枚举值、CSS 属性、DOM 标识、平台请求及布局历史中的操作值不依赖语言。

## 切换语言的状态约束

- 连接列表不因语言切换重新加载；保留名称、密码和正在进行的连接测试。
- 对象树保留搜索、展开与选择；表名、字段名、SQL、注释和用户草稿保留原文。
- 关系编辑保留映射和备注，不因翻译变化重跑验证或保存。
- CodeMirror 用 `Compartment.reconfigure` 更新占位文案、无障碍名称和补全标签；不重建编辑器，不丢失光标、选区与撤销历史。
- 查询不中断、不重发；已返回结果保留。日期、界面统计及错误类别按应用语言显示；数据库结果值和服务端诊断保持原样。
- 历史页保留所选 Before/After 版本和比较方向，不重新加载快照列表。
- 画布保留展开的工具面板与选择；布局手势使用稳定操作标识。密集图的边投影与绘制缓存保留原有对象身份。
- 保存视图对话框通过稳定 DOM 选择器恢复焦点，不依赖翻译后的 `aria-label`。
- 异步事件反馈使用 `useEventTranslator`；已有事件记录保留事件发生时的文字，切换语言不会重放操作。

## 共享设计系统

- `design-system/Button.tsx` 支持原生 ref，连接管理、关系删除和查询导出复用按钮变体与忙碌/禁用语义。
- `design-system/EmptyState.tsx` / `surfaces.css` 为连接列表、查询结果和查询历史提供统一空状态。文案与操作由调用页面传入。
- 扩充弹窗内边距、圆角和空状态间距令牌；业务浮层与弹窗复用阴影、遮罩、控件圆角、字号与行高。
- 页面特有布局及画布几何尺寸保持组件负责；未宣称所有历史 CSS 均已迁移。

## 验证

- `BusinessPages.i18n.test.tsx`：7 个语言切换行为测试，覆盖连接、树、知识草稿、关系、SQL 编辑器/查询、历史与画布工具。
- `SchemaCanvas.test.tsx`：新增 Web 与历史预览两种模式的语言切换回归，确认选择、布局位置、撤销历史保留，且不触发重新布局。
- `business-coverage.test.ts`：元数据标签覆盖检查，以及已迁移业务文件的静态 JSX 文案检查。技术标识和示例地址有明确白名单。
- 完整前端测试：134 个文件、862 个测试全部通过；`pnpm lint`、TypeScript 检查与 `pnpm build` 通过。生产构建仍提示部分压缩后分块超过 500 kB，未影响构建完成。
- 浏览器模拟预览：中文模型页、连接表单、查询执行/结果、切换英文后保留 SQL 与结果、深色关系编辑页，以及 18px 字号下的关系管理布局。
- `business-preview.html?language=zh-CN&theme=light` 提供可重复的开发预览；支持 `language=en`、`theme=dark`、`font=18`。使用合成数据，不连接数据库，不写入真实业务数据，不进入生产构建入口。

## 保留边界

- 数据库/驱动/Rust 后端的原始诊断、采集覆盖说明、推断证据正文与预检规则的动态解释未做字符串猜测翻译；后续应通过结构化错误码、消息键和参数在生产者侧接入。
- SQL、DDL、数据库标识符、用户注释/知识、模型回答、Git 提交信息和查询结果保持来源语言。
- 导出对话框已翻译；独立 HTML 报告/离线 Viewer 的完整文档国际化、原生菜单和安装/更新原生界面属于后续阶段。
- 实际 Tauri WebView、Windows/Linux 字体差异及真实数据库连接仍需桌面验收；浏览器模拟和自动化测试不替代这些检查。
