# Nodal Studio v0.2.3

## 中英文界面与统一设计

- 设置、主导航、数据源、对象树、详情面板、关系图、查询和历史支持简体中文与英文切换。
- 统一共享组件、主题颜色、间距和交互状态，优化高级更新设置及功能支持页面。
- 改进主导航选中状态与首次切换查询的显示体验，统一可点击控件的鼠标样式。
- 新设置及恢复默认设置时，界面缩放默认为 110%；保留已保存的缩放偏好。

## 更完整的数据库对象

- PostgreSQL / MySQL 新增函数、存储过程、触发器采集和只读详情；保留 PostgreSQL 重载函数签名。
- 展示数据库目录确认的依赖与被引用关系，支持跳转到相关对象。
- 完善物化视图、索引及约束详情，并将新增对象和依赖变化纳入结构历史比较。

## 中央对象文档

- 函数、视图、物化视图、存储过程和触发器在中央文档打开，左侧对象树保持稳定。
- 返回关系图保留画布现场；定义支持语法高亮、行号、换行、复制和查找。
- 属性与依赖分区展示，采用独立的函数、存储过程和触发器图标，并修正操作菜单图标对齐。

## 使用说明

- 对象定义及依赖的可见性受数据库权限限制；动态 SQL 和字符串形式的函数体不保证完整依赖分析。
- 首次重新采集可能因元数据覆盖范围扩大而出现新增对象记录，不一定代表数据库最近发生了变更。
- 中央文档当前为单个可复用视图，尚不支持固定多个文档标签。
- macOS 目标为 Universal 安装包，支持 Apple Silicon 和 Intel。Windows 安装包仍属于独立的未签名测试渠道。
