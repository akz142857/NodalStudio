# Nodal Studio v0.2.3

## English and Chinese Interface, Unified Design

- Switch between English and Simplified Chinese across settings, main navigation, data sources, the object tree, detail panels, relationship diagrams, queries, and history.
- Shared components, theme colors, spacing, and interaction states provide a consistent interface, with refinements to Advanced Update Settings and Feature Support.
- Improved active navigation states and the first transition to Queries, with consistent pointer cursors for clickable controls.
- UI scale defaults to 110% for new preferences and when restoring defaults. Existing saved scale preferences are preserved.

## Expanded Database Object Support

- Added PostgreSQL and MySQL collection and read-only details for functions, stored procedures, and triggers, including overloaded PostgreSQL function signatures.
- Browse dependencies and references confirmed by database catalogs, and navigate to related objects.
- Expanded materialized view, index, and constraint details. Schema history comparisons now include the newly supported objects and dependency changes.

## Central Object Documents

- Functions, views, materialized views, stored procedures, and triggers open in the central document area while the left object tree stays in place.
- Returning to the relationship diagram preserves the canvas state. Definitions support syntax highlighting, line numbers, line wrapping, copy, and search.
- Properties and dependencies appear in separate sections, with distinct function, stored procedure, and trigger icons and corrected action-menu icon alignment.

## Usage Notes

- Database permissions affect the visibility of definitions and dependencies. Complete dependency analysis is not guaranteed for dynamic SQL or function bodies stored as strings.
- The first metadata refresh may report newly discovered objects because collection coverage has expanded; these entries do not necessarily indicate recent database changes.
- The central document area currently provides a single reusable view. Pinning multiple document tabs is not yet supported.
- The macOS Universal installer supports Apple Silicon and Intel. Windows installers remain part of a separate unsigned testing channel.

## Windows x64 Installation and Upgrades

`Nodal-Studio_0.2.3_windows-x64-unsigned-setup.exe` and its SHA-256 checksum file are now available. **The Windows package is an unsigned test build** and may trigger SmartScreen or organization policy restrictions.

Clean installation, launch, persistence across restarts, uninstallation, and an **in-place installer upgrade from 0.1.0 to 0.2.3** passed acceptance on a real Windows Server 2022 x64 environment. Settings, connections, and Windows Credential Manager credentials were retained after the upgrade.

Windows in-app automatic updates are not enabled yet. Quit the previous version, download this installer, and run it using the existing installation directory to upgrade. Machines without WebView2 need internet access to install the runtime. Physical Windows 10/11 devices, the first-download SmartScreen experience, and machines without WebView2 have not yet completed acceptance testing.
