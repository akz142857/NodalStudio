# Nodal Studio v0.2.5

This release adds a local change-review workspace and improves field navigation, SQL editing, and AI reply preferences.

## Review database changes

- Review structure changes and their impact on descriptions, logical relationships, business domains, and saved views in one workspace.
- Keep a separate baseline and review history for each connection. Confirm or revise descriptions, defer items with a reason, or archive obsolete descriptions before completing a review.
- Search and page through review items, mark structure changes as reviewed in batches, and restore archived descriptions for a new review.
- Preview actions before applying them. Review actions update local knowledge and do not execute database schema changes.

## Field navigation and SQL editing

- Highlight the selected field in the table inspector and locate it from the diagram, keeping table and field selection aligned.
- Copy, cut, paste, select all, and format SQL from the editor context menu. Formatting follows the current PostgreSQL or MySQL dialect and supports undo.
- Improve scrolling and bilingual labels in SQL drafting and query composition.

## AI preferences and settings

- Save reply language, level of detail, terminology style, and optional additional instructions per connection.
- Keep AI settings drafts and save/discard controls available while navigating settings. Requests retain their existing preview, consent, and read-only validation requirements.
- Improve privacy information, third-party notices, and file access handling.
- Separate development and production application identities.

## macOS installation

The Universal macOS installer supports Apple Silicon and Intel Macs. The application and disk image are signed with Developer ID and notarized by Apple. Existing macOS users can update through the app.

## Windows x64 installation and upgrades

The Windows x64 installer is an **unsigned test build**. It may trigger SmartScreen or organization policy restrictions. Windows in-app automatic updates remain unavailable; quit the previous version and run the installer using the existing installation directory.

Clean installation and an in-place upgrade from v0.2.4 are validated on Windows Server 2022 x64 before publication. Physical Windows 10/11 devices, SmartScreen UX, and machines without WebView2 are outside this acceptance scope. Machines without WebView2 need internet access to install the runtime.
