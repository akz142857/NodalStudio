# Nodal Studio v1.4.2

## Personal connection sync

- In Settings → Cloud Sync, choose a local iCloud Drive or Google Drive folder. Start an empty encrypted library, include your existing connection profiles in a new library, or preview a merge with a library already in the folder.
- Changes to connection profiles are encrypted and written automatically. Review incoming updates before merging. When both devices edit the same profile, the merge keeps both versions.
- Database and SSH passwords, private keys, certificates, and SQLite database files stay on the device where you configured them.

## Data source picker

- Edit current connection and Manage connections stay visible beneath the scrollable list, even when you have many data sources.

## Install or update

- The signed and notarized Universal macOS package supports Apple Silicon and Intel. Existing direct-download installations can update through the app.
- The Windows x64 installer is an unsigned test build. SmartScreen or organization policy may restrict installation. Quit Nodal Studio and run the installer in the existing installation directory to upgrade manually.
