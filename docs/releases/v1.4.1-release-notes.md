# Nodal Studio v1.4.1

## Appearance and accessibility

- The Query Run button is easier to read on hover in both Light and Dark modes.
- Query draft charts use higher-contrast marks and a shape cue for the highlighted bar. macOS Increase Contrast also strengthens chart marks and selection indicators.
- Selected objects, Settings categories, and query result rows are easier to spot. Toolbar and canvas icons have consistent sizing and stroke weight.
- Blue remains the default accent. On macOS, controls and selection indicators adapt to your system accent color.

## Install or update

- The signed and notarized Universal macOS package supports Apple Silicon and Intel. Existing direct-download installations can update through the app.
- The Windows x64 installer is an unsigned test build. SmartScreen or organization policy may restrict installation. Quit Nodal Studio and run the installer in the existing installation directory to upgrade manually.
