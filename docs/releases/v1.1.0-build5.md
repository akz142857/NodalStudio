# Nodal Studio 1.1.0 Build 5

日期：2026-11-07（Asia/Singapore）。基于主干 `dc58d5b` 修复 [严重问题审查](v1.1.0-main-critical-review.md) 中的三项 P1。App Store 候选为 1.1.0 / Build 5；已公开 GitHub v1.1.0 标签与资产保持原样。

## 修复范围

- 导入模型不改变已有本机连接身份；新网络来源离线恢复，连接前要求重新输入凭据。备份及设置文件导入不覆盖本机 AI/Cloud/Git 绑定，也不能开启自动连接。
- portable import 在事务内校验对象归属和引用；跨来源冲突整体拒绝。共享分组/视图/关系保存方法也禁止转移其他来源的对象。
- Git 工作区通过固定目录句柄和不跟随链接的访问保护根目录、父目录、清单、读写及旧文件删除；临时文件替换防止截断硬链接目标。
- 添加 9 条针对性回归测试，并更新第三方许可证清单。

## 打包与上传交接

使用私有本机构建配置（不入 Git），设置 `APP_BUILD_NUMBER=5`、Universal 架构、正式 MAS 应用与安装包签名，执行 `Scripts/build_macos_appstore.sh`。安装包目标位置：

`dist/app-store/Nodal-Studio-1.1.0-5.pkg`

构建后的版本、架构、签名、包摘要及源码提交证据记录在本机 `target/mas-1.1.0-build5/verification.json`，构建是否成功以该证据和实际产物为准，本源码记录不预先宣称构建完成。

App Store Connect 的 1.1.0 版本说明已补充导入及 Git 文件边界修复。选择审核附件时浏览器控制被访问限制终止，尚未上传安装包/附件，也未提交审核。用户随后明确由自己上传 Build 5；本轮交付本地安装包，不继续操作商店上传或审核提交。价格、地区、购买模式未改动。
