# Nodal Studio v1.5.0

## Database connections

- Save a PostgreSQL or MySQL server connection, browse its databases, and create a database when your account has permission.
- Connect through SSH with an encrypted private key and its passphrase.
- The Connection dialog gives fields more room during tests. On shorter windows, a compact footer keeps test progress and **Cancel test** visible while you scroll through the form.
- Connection sync accepts passphrases starting at four characters. Cloud Sync settings and the toolbar now make sync status easier to find.

## Workspace improvements

- Global search updates without re-rendering the rest of the workspace. Ontology and Change Review load when you open them.
- The ontology definition editor adapts to narrower windows. The SQLite table editor shows whether you are in read-only or editing mode.
- Small UI text follows the configured font size, with an 11 px minimum.

## Self-hosted Cloud

- The Cloud API compresses responses and lets clients revalidate unchanged shared views. Rate limits apply per client as well as globally. Deployments behind a trusted reverse proxy can enable `TRUST_PROXY_HEADERS=1` when the proxy overwrites `X-Real-IP`.

## Install or update

- The signed and notarized Universal macOS package supports Apple Silicon and Intel. Existing direct-download installations can update through the app.
- The Windows x64 installer is an unsigned test build. SmartScreen or organization policy may restrict installation. Quit Nodal Studio and run the installer in the existing installation directory to upgrade manually.
