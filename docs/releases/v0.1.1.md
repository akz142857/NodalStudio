# Nodal Studio 0.1.1

Nodal Studio now uses GitHub Releases for signed in-app updates on macOS.

- Check, download, verify, install and restart from Settings > Updates & About.
- Updates are verified with the embedded production public key before installation. The installer backs up the existing application and local SQLite database.
- The universal macOS build supports Apple Silicon and Intel and is signed with Developer ID and notarized by Apple.
- Builds without an updater key and Windows builds can check GitHub release versions and open the download page for manual installation.
- Improved update source/status messages, missing-feed errors and release artifact validation.

## Installing this first updater-enabled release

Users of the original 0.1.0 release must install the 0.1.1 DMG manually once, because that release does not contain the production updater public key. Subsequent signed macOS releases can be installed inside the app. Quit Nodal Studio, open the DMG, and replace the app in Applications; local data remains in Application Support.

Use `Nodal-Studio_0.1.1_universal.dmg` for manual installation. The `.app.tar.gz`, `.sig` and `latest.json` assets are consumed by the updater. `SHA256SUMS` records checksums of the two packages.

This release contains macOS artifacts only. The Windows 0.1.0 unsigned test installer remains available in its original release; Windows in-app installation is not enabled.
