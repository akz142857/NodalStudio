# Nodal Studio v0.1.0

Nodal Studio is a local-first desktop workspace for exploring database structure,
documenting its business meaning, and reviewing schema changes.

## Highlights

- Capture PostgreSQL and MySQL schema metadata and explore tables, fields,
  indexes, and relationships in an interactive ER diagram.
- Search and focus large models, save layouts and relationship views, and add
  model-only logical relationships without altering database constraints.
- Compare local snapshots and inspect structural changes and their history.
- Document tables and fields with annotations, business domains, and reviewed
  knowledge. Optional AI assistance supports table understanding, business-language
  discovery, and evidence-linked relationship explanations, with request previews
  and explicit confirmation before saving knowledge.
- Export diagrams as SVG/PNG, generate HTML data dictionaries and interactive
  offline viewers, and preview PostgreSQL/MySQL DDL without executing it.
- Run bounded, read-only PostgreSQL queries. Database credentials are stored in
  the system Keychain.
- Share selected metadata through an optional self-hosted Cloud API and read-only
  Web viewer, or collaborate through a split-file Git semantic workspace.
- Use unified settings for appearance, data sources, AI, privacy, and project
  policy. This release preserves source AI settings and managed policy when saving
  the most recently used workspace, including when switching between sources.

## Distribution

The desktop release targets macOS, with a Universal build for Apple Silicon and
Intel. Windows and Linux installers are not included in this release.
The website-download DMG and Mac App Store package use separate signing workflows.

The DMG and its application are Developer ID signed and Apple notarized.
Open the DMG, copy **Nodal Studio** to
**Applications**, then launch it from Applications. Compare the downloaded DMG's
SHA-256 with the checksum supplied alongside that exact release asset.

## Scope and limitations

- Metadata capture does not read application rows. Explicit PostgreSQL Query
  operations do read query results; MySQL and Web SQL execution are unavailable.
- The offline AI provider supplies deterministic structural evidence. Model-based
  answers require a configured compatible service and credentials; they are not
  included as a hosted service with the application.
- AI statements require review. Independent business-owner evaluation and physical
  two-device acceptance remain separate from automated verification.
- MySQL metadata coverage and DDL preview support are limited to the implemented
  object/statement subsets. Physical schema editing and migration execution are
  not supported.
- Cloud sharing requires a separately configured server. It is disabled by default.
- The application-update implementation is included, but the default v0.1.0 build
  has no production update endpoint or updater public key. It therefore does not
  provide a live automatic-update channel. A later updater-enabled build must be
  installed manually before that channel can be used.
