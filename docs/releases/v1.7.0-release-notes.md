# Nodal Studio v1.7.0

## Code Review

- Open local project folders from the new **Code** workspace without a database connection. Save and group projects, browse source files, and search across file names and contents.
- Compare Git working-tree changes against the baseline, switch between a diff and the full source, and record review status and notes for each changed file.
- Check Markdown in the workspace and jump from findings to the matching source lines.
- Use Quick Open, close and reopen tabs, and navigate with Code shortcuts listed in Settings. On macOS, Command-W closes the current Code tab and asks for confirmation if an untitled draft contains edits.

## Query and connections

- Query offers the appropriate action for the current SQL, including opening a read-only preview for supported schema statements.
- The Connection Sync entry is easier to spot below the empty connection list.

## Install or update

- The signed and notarized Universal macOS disk image supports Apple Silicon and Intel. Existing direct-download installations can update through the app.
- On Windows, quit Nodal Studio and run the x64 installer in the existing installation directory to upgrade. The installer is unsigned, and SmartScreen or organization policy may restrict installation.
