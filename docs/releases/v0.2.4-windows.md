# Nodal Studio v0.2.4 — Windows x64

The Windows package is an **unsigned test build**, distributed as a per-user NSIS installer. It is attached to the same v0.2.4 release as the signed macOS package.

## Installation and upgrades

Download `Nodal-Studio_0.2.4_windows-x64-unsigned-setup.exe` and its `.sha256` file from the [v0.2.4 release](https://github.com/akz142857/NodalStudio/releases/tag/v0.2.4). Verify the checksum using PowerShell `Get-FileHash -Algorithm SHA256 <installer-path>`.

Quit the previous application and run the installer using its existing installation directory. Windows in-app automatic downloads and installation remain disabled; use the release installer to upgrade. WebView2 Evergreen is required, and installing a missing runtime requires network access. SmartScreen or organization policies may restrict unsigned packages; no security bypass was used during acceptance.

## Acceptance results

Both runs used actual Windows Server 2022 x64 runners with WebView2 installed. Checks covered a Chinese/space-containing installation path, real installed application launch and native IPC, runtime version, binary identity (normalizing only Tauri's NSIS bundle marker), SQLite settings/source persistence, Windows Credential Manager persistence, and silent uninstall.

The upgrade run installed public v0.2.3, saved a dark theme and disposable connection/credential, closed the application, installed v0.2.4 into the same directory, and verified that all persisted. Native WebView2 screenshots were inspected and show the rendered dark-theme application after restart/upgrade. Both lifecycle receipts reference the same installer checksum.
