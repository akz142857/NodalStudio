## Actual GitHub upgrade round trip

Performed on Apple Silicon through the native Settings > Updates & About UI. The baseline was a **locally built, ad-hoc-signed 0.1.0 test copy containing the new production public key**, built from the release source. It used the production bundle identifier so that the actual production archive could be installed. It was not the original published v0.1.0, and it is not a distributable release.

The test copy was installed under `dist/releases/v0.1.1-acceptance/installed/Nodal Studio.app`. The existing `/Applications/Nodal Studio.app` was not replaced. Before running the baseline, the existing SQLite data was backed up with the SQLite backup API and passed `PRAGMA integrity_check`.

| Step | Observed result |
| --- | --- |
| Check real GitHub source | Installed 0.1.0; available 0.1.1 |
| Download actual published archive | Ready to install; Signature verified |
| Defer installation | Not now returned to Ready to install, preserving verified bytes |
| Install | Created an app backup and verified SQLite backup, then replaced the test app |
| Automatic restart | Old process exited; a new process opened the same app path with the production window title |
| Version and installed files | Settings reported 0.1.1; every installed app file matched the production bundle |
| Check again | Nodal Studio is up to date |
| Data preservation | All 19 data/settings tables matched their pre-test row digests in both live data and automatic backup; only `external_access_log` changed to record the requested update access |
| Database integrity | Live database and automatic backup both passed full integrity checks |

Immediately after publication, GitHub briefly redirected the updater's JSON request to the previous release. The app reported a missing manifest and allowed retry. Once GitHub's redirect cache propagated, the same default endpoint succeeded without settings or code changes. A failed check was never reported as up to date.

Private local evidence is retained under `dist/releases/v0.1.1-acceptance/`: the pre-test SQLite backup, table digests, downloaded GitHub assets, public manifest and post-upgrade verification JSON. The updater's own backup is in the application's `update-backups/0.1.0-29f4a72b-89e3-4e44-829c-2d94cbf44f45` directory. Do not publish those databases or user-data evidence.
