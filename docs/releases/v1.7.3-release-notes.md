# Nodal Studio v1.7.3

## Code review

- Changes shows the current Git worktree and checked-out branch. Switch between worktrees and review either local changes or committed differences against the default branch.
- Changes refreshes after external staging, unstaging, or commits. The open file and its reading position stay in place during the refresh, and reviewed versions retain their review status.
- Source view highlights added and modified lines with the same background as Diff and marks deletion positions in the gutter.
- On macOS, use **Reveal in Finder** from file and folder context menus in Code.

## Model canvas

- Hold Command on macOS or Ctrl on Windows and scroll up to zoom in or down to zoom out. Each step uses the same increment as the canvas zoom buttons.

## Install or update

- The signed and notarized Universal macOS installer supports Apple Silicon and Intel. Existing GitHub macOS installations can update in the app.
- Windows users can upgrade manually with the unsigned x64 installer. Quit Nodal Studio before running the installer in the existing installation directory.
