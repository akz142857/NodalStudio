# Nodal Studio v1.3.0

## Database workspace

- Browse table data with database-side pagination, sorting, and filters. Set the page size, jump to a page, or request the last page. Each table remembers its page, scroll position, column widths, sort, and applied filters.
- Combine filter conditions and disable individual conditions while keeping their values. Read column comments by hovering over headers and open a table's DDL from the data workspace.
- Copy cell values or rows as tab-separated text and generate INSERT or UPDATE statements for supported tables.
- Add, edit, or delete SQLite rows in the table grid. Row changes stay in drafts until you save, and a failed transaction keeps the drafts available to retry.
- Browse views and PostgreSQL materialized views, inspect supported routines and MySQL events, and reopen named queries saved for each connection.

## Query and Model

- Run read-only SQL in Quick Query while browsing a table. The editor floats or docks above the data grid, which displays the query results.
- Run supported table and index DDL in Query on SQLite, MySQL, and PostgreSQL with an explicit confirmation.
- Refresh Model to see added and modified tables on the diagram. Select a table to inspect its before-and-after changes. Use History to compare snapshots, including changes involving removed tables.

## Install or update

- The signed and notarized Universal macOS build supports Apple Silicon and Intel. Existing direct-download installations can update through the app.
- The Windows x64 installer is an unsigned test build. SmartScreen or organization policy may restrict installation. For a manual upgrade, quit Nodal Studio and run the installer in your existing installation directory.
