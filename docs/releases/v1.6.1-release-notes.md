# Nodal Studio v1.6.1

- Open and refresh large MySQL databases faster. Schema reads fetch foreign keys and check constraints in batches.
- Load large SQLite files faster. Each schema read reuses catalog metadata and the columns referenced by foreign keys.
- Switch between saved databases faster across MySQL, PostgreSQL, and SQLite. The workspace loads recent snapshot references, and the history panel loads the full history when opened.
- Reopen the database picker without waiting for the list to reload. Previously loaded databases stay available while the list refreshes.

## Install or update

- The signed and notarized Universal macOS disk image supports Apple Silicon and Intel. Existing direct-download installations can update through the app.
- On Windows, quit Nodal Studio and run the x64 installer in the existing installation directory to upgrade. The installer is unsigned, and SmartScreen or organization policy may restrict installation.
