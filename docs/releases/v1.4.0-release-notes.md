# Nodal Studio v1.4.0

## Ontology and change review

- Define paid orders by mapping orders and payment events to tables, fields, a success status, and a business time zone. Generate a read-only query for orders first paid in the previous business month.
- Reuse a confirmed definition in Query. When a structural change affects a binding, review the impact, record the reason for the new mapping, and rerun an approved sample. Review compares the actual and expected order IDs, including missing and unexpected IDs.
- Paid-order definitions support PostgreSQL, MySQL 8+, and SQLite. Table and field pickers support searching by name.

## Desktop workspace

- Switch between Model, Ontology, Database, and Query with Command+1 through Command+4 on macOS or Ctrl+1 through Ctrl+4 on Windows. Find the same actions in the command palette and Keyboard Shortcuts settings.
- Explore snapshot history with searchable comparison controls and expandable fingerprints. Selecting the newest snapshot returns to the live model. Historical definitions are read-only.
- Use the redesigned inspectors and Settings forms, including consistent controls and keyboard focus. The SQL editor uses a compact, even inset.
- Remove saved connections from Manage Connections. If a connection has no schema snapshot, open Edit Connection and choose Verify and Refresh.

## Install or update

- The signed and notarized Universal macOS package supports Apple Silicon and Intel. Existing direct-download installations can update through the app.
- The Windows x64 installer is an unsigned test build. SmartScreen or organization policy may restrict installation. Quit Nodal Studio and run the installer in the existing installation directory to upgrade manually.
