重点检查：

| 边界 | 源码与结果 |
| --- | --- |
| SQLite 原库保护 | `sqlite-adapter::connect` 使用结构化 filename、只读打开、不建库、query_only、trusted_schema=OFF；没有迁移、journal_mode 切换或 checkpoint。SQL 校验拒绝写操作、多语句、ATTACH、扩展与文件函数。WAL 辅助文件访问不被描述为整个目录逐字节不变。 |

| MAS 边界 | 购买状态由 StoreKit 验证；未列入免费恢复清单的新 IPC 默认要求购买证明；云协作和自更新对 MAS 被后端禁止。文件授权来自原生选择器与本地 bookmark，备份不授予权限。 |
