# Nodal Studio v1.0.2

This release simplifies database connection setup and separates Mac App Store updates from purchase verification.

## Database connections

- New connections default to TLS disabled. Enable the TLS mode required by your database when needed. Existing connections and saved custom defaults keep their settings.
- Remove the persistent connection-success message from the sidebar after a connection is saved and its schema is mapped. Connection errors remain visible.

## Mac App Store interface

- Show a separate, compact Mac App Store updates card with the current version and an Open App Store button.
- Keep purchase status and purchase verification in their own card, with updated English and Chinese labels.
- App Store updates continue to be managed by Apple. This GitHub release does not upload or publish an App Store update.

## macOS installation

The Universal macOS installer supports Apple Silicon and Intel Macs. The application and disk image are signed with Developer ID and notarized by Apple. Existing direct-download macOS users can update through the app.

## Windows x64 installation and upgrades

The Windows x64 installer is an **unsigned test build**. It may trigger SmartScreen or organization policy restrictions. Windows in-app automatic updates remain unavailable; quit the previous version and run the installer using the existing installation directory.

Clean installation and an in-place upgrade from v1.0.1 are validated on Windows Server 2022 x64 before publication. Physical Windows 10/11 devices, SmartScreen UX, and machines without WebView2 are outside this acceptance scope. Machines without WebView2 need internet access to install the runtime.
