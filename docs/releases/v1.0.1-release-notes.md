# Nodal Studio v1.0.1

This release aligns the product version across distribution channels and keeps the diagram stable during unchanged schema refreshes.

## Consistent product versions

- GitHub, Windows and Mac App Store builds now use the same shared product version: **1.0.1**.
- App Store builds inherit the shared version instead of maintaining a separate version override. Packaging checks reject a version mismatch between channels.
- App Store build numbers remain independent. This GitHub release does not upload or publish an App Store update; App Store installations continue to receive updates through Apple.
- v1.0.1 follows GitHub v0.2.5 to align with the existing App Store 1.0 version line. Existing release tags remain available.

## Stable schema refreshes

- Keep the diagram canvas height stable when a background refresh finds no structure changes.
- Keep refresh progress in the application refresh control and retain capture-time information in the snapshot details.
- Continue to show refresh failures without replacing the captured model.

## macOS installation

The Universal macOS installer supports Apple Silicon and Intel Macs. The application and disk image are signed with Developer ID and notarized by Apple. Existing direct-download macOS users can update through the app, including from v0.2.5.

## Windows x64 installation and upgrades

The Windows x64 installer is an **unsigned test build**. It may trigger SmartScreen or organization policy restrictions. Windows in-app automatic updates remain unavailable; quit the previous version and run the installer using the existing installation directory.

Clean installation and an in-place upgrade from v0.2.5 are validated on Windows Server 2022 x64 before publication. Physical Windows 10/11 devices, SmartScreen UX, and machines without WebView2 are outside this acceptance scope. Machines without WebView2 need internet access to install the runtime.
