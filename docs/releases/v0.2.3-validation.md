# v0.2.3 release preparation

Status: signed/notarized release draft prepared; not published. The latest public release at preparation time is v0.2.1. Version 0.2.3 was explicitly selected for the tested changes and remains unchanged.

## Release scope

Public release notes: `docs/releases/v0.2.3-release-notes.md`.

Includes bilingual UI/shared design system, PostgreSQL/MySQL programs and dependencies, richer catalog details/history, central object documents, settings polish, object icons and the 110% default scale. Historical local package evidence remains in `v0.2.3.md` and `v0.2.3-object-documents.md`; those signed, unnotarized test DMGs are not formal updater releases.

Native acceptance of the latest test DMG is recorded in `docs/LOCALIZATION_NATIVE_ACCEPTANCE.md`, including light/dark themes and 110% scaling. This does not establish notarization or an installed-updater upgrade round trip.
