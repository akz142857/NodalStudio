# v0.2.2-beta.1 — Localization and shared UI test build

This is a macOS test build for the English/Simplified Chinese interface and shared design system. It is not a published stable release.

- Adds typed language catalogs, persisted language selection, localized settings, navigation, data sources, schema tree, inspector, canvas, relationships, queries and history.
- Consolidates colors, spacing, buttons, forms, empty states and native-select styling into shared primitives.
- Localizes coded connection/relationship diagnostics and the native query-export title while preserving database values, SQL and unknown upstream diagnostics.
- Fixes canvas clipping and relationship endpoint offsets at larger application UI scales.
- Makes the selected navigation segment explicit, keeps the application shell mounted during first-use lazy loading, and gives clickable controls a shared pointer/hover affordance.

Native acceptance used isolated PostgreSQL/MySQL fixtures on macOS. See `docs/LOCALIZATION_NATIVE_ACCEPTANCE.md` for coverage and boundaries. The package uses the regular application identifier and local-data location; no automatic installation or public Release publication is part of this task.
