# Nodal Studio v1.6.0

## Database connections

- Create PostgreSQL and MySQL connections with guided fields, or open a local SQLite file. Choose a database by name or browse the databases available to your account after connecting.
- Connection, TLS, and SSH settings share a dialog that fits the window and keeps its height while fields or test results change. Connection tests show separate SSH, TLS, and database status and can be cancelled.
- Saved server connections can be synced between devices. Each device completes its own credential and file setup. Older versions continue to sync individual database connections. Importing a file that contains server connections requires v1.6.0 or later.

## Model canvas

- Save selected tables as a model view directly from the selection or beside Select. Delete saved views from the sidebar or the view menu.
- Drag the canvas tools anywhere on the canvas. The minimap stays compact until you hover over it and continues to support clicking, panning, and zooming.
- The desktop window fits the display's usable area when it opens.

## Install or update

- The signed and notarized Universal macOS disk image supports Apple Silicon and Intel. Existing direct-download installations can update through the app.
- On Windows, quit Nodal Studio and run the x64 installer in the existing installation directory to upgrade. The Windows installer is unsigned, and SmartScreen or organization policy may restrict installation.
