# Nodal Studio 0.2.0

Nodal Studio 0.2.0 adds MySQL queries and AI SQL drafting, a conversational drafting workspace, and a faster way to review inferred relationships. It also simplifies source navigation and improves canvas and update reliability.

## MySQL and AI drafting

- Run bounded, read-only MySQL queries with dialect-aware completion, cancellation, precise BIGINT/DECIMAL results, export and local history.
- Generate MySQL AI SQL drafts using the current snapshot and reviewed physical or logical relationships. Generating, opening a draft in the editor and executing it remain separate actions.
- Draft query now uses a conversation layout: responses above, an automatically growing composer below, and structured json-render result/chart cards.
- Changes stays clickable and explains the next step when no comparison is available.

## Relationship review

- Manage logical relationships with a compact list and same-page details, editing and creation.
- Review inferred candidates with search, scope/evidence filters, confirm-and-next, ignore and restore.
- Select multiple candidates and preview them in mapping groups before confirming. Large groups show a compact preview that can expand to all mappings; individual mappings and whole groups can be excluded.
- Type differences, ambiguous targets and conflicting mappings remain in individual review. Each eligible group still requires a business-meaning check before batch confirmation.
- Batch confirmation, ignore and restore are saved atomically. Device-local batch history survives restart; undo preserves items that were edited afterward.
- Canvas tools show the three relationship visibility switches directly.

## Workspace and reliability

- A consistent source picker shows connection details and connection actions in its popover. Removing one of several sources keeps the remaining model usable.
- The right inspector is hidden by default and opens from the toolbar. Saved user preferences remain respected, and delayed settings reads no longer undo an explicit open/close action.
- Saved model views retain their own layouts; historical model positions remain isolated from the latest model.
- Large-diagram arrangement and local-storage recovery are more robust.
- Table AI answers lead with an evidence-backed summary, supporting points and important unknowns. Requests are prepared locally; sending remains explicit.
- Description confirmation separates successful saving from a failed refresh. Cancellation invalidates borrowed draft requests, and stricter prompt examples reduce invalid response formats.
- macOS packaging selects only the current-version DMG; updater generation validates the complete archive stream and compares versions using SemVer precedence.

## Installation and scope

The macOS Universal DMG supports Apple Silicon and Intel. Release assets include the Developer ID-signed and Apple-notarized DMG, the signed updater archive and signature, `latest.json`, and `SHA256SUMS`.

Users on 0.1.1 or 0.1.2 can upgrade through **Settings > Updates & About**. Users on 0.1.0 install the DMG manually. Windows remains an unsigned test distribution with manual installation through its separate CI packaging workflow.

Logical relationships and their review history do not create database foreign keys. SQL queries run only after an explicit action; AI drafts are suggestions, and structure checks do not establish business meaning. This version adds local batch-history tables while retaining the existing local schema-version number and preserving existing data.

See the [validation record](https://github.com/akz142857/NodalStudio/blob/main/docs/releases/v0.2.0-validation.md) for automated checks, native acceptance, distribution verification and remaining platform/AI limitations.
