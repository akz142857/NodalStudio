# Nodal Studio 0.2.0

Release candidate — prepared on 2026-10-23; not yet published.

This release simplifies single-table AI explanations and fixes recovery, cancellation and macOS release packaging.

- The table assistant prepares the request locally as you edit. Sending still requires an explicit action; opening the panel or choosing a suggestion does not contact the model.
- Answers lead with a concise, evidence-backed summary, up to three supporting points and up to three important unknowns. Request details and evidence remain available on demand.
- An answer can be reviewed and edited as one table-description draft before local confirmation. Chinese and English labels follow the application setting.
- Choosing the suggestion already in the composer now prepares a fresh request correctly instead of leaving Send disabled.
- A saved description remains marked as saved if refreshing the view fails. Retry refresh reloads the view without submitting the description again.
- Cancelling a completed explanation invalidates draft requests that have already borrowed that answer, including cancellation during asynchronous revalidation.
- macOS packaging rejects missing or ambiguous current-version DMGs instead of selecting an older artifact. Update manifest creation checks the complete gzip stream, and update checks ignore SemVer build metadata when deciding whether a version is newer.

## Upgrade plan

The intended release assets are `Nodal-Studio_0.2.0_universal.dmg`, the signed `.app.tar.gz` and `.sig`, `latest.json`, and `SHA256SUMS`. They must be built, signed and notarized on a configured release Mac before publication. The local development bundle is not a distribution artifact.

Users on 0.1.1 or 0.1.2 will be able to upgrade through **Settings > Updates & About** after the signed release is published. Users on 0.1.0 need the manual DMG installation. There is no local database migration in this release. Windows installation remains manual.

See the [v0.2.0 validation and remaining release gates](v0.2.0-validation.md). Previous-version model results do not establish acceptance of the new answer contract.
