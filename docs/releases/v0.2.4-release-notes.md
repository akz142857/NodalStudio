# Nodal Studio v0.2.4

This release improves DDL import, structure preflight, and export navigation.

## DDL import workspace

- Import SQL files or clipboard text through a dedicated panel, with dialect and default namespace controls shown directly.
- Preview a temporary, read-only model in the central workspace with a diagram, object tree, structure details, and parsing diagnostics.
- Return to the database without losing its diagram state, then resume the temporary model.
- Jump from table, column, or diagnostic details to the relevant SQL source. Closing a non-empty session requires confirmation.
- DDL preview does not connect to a database or execute SQL.

## Structure preflight

- Separate check findings from rule coverage, with evidence and recommendations displayed in the right inspector.
- Preserve filters, selection, expanded rules, and review drafts when navigating to the diagram and back.
- Show naming hints as a direct checkbox and simplify the workspace header.
- Localize rule explanations, findings, recommendations, and evidence labels in English and Simplified Chinese.
- Continue to check captured metadata only; findings do not certify database validity or execute repair SQL.

## Interface refinements

- Rename export actions to **Export structure document** and **Export interactive viewer**, with clearer descriptions of their purposes.
- Align dependency sections and reuse shared controls, spacing, and theme styles.

## macOS installation

The Universal macOS installer supports Apple Silicon and Intel Macs. Existing macOS users can update through the app. The downloadable files contain the same v0.2.4 application.

## Windows x64 installation and upgrades

`Nodal-Studio_0.2.4_windows-x64-unsigned-setup.exe` and its SHA-256 checksum file are provided for Windows x64. **The Windows package is an unsigned test build** and may trigger SmartScreen or organization policy restrictions.

Clean installation, application launch, persistence across restarts, uninstallation, and an **in-place installer upgrade from 0.2.3 to 0.2.4** passed on Windows Server 2022 x64. Settings, connections, and Windows Credential Manager credentials were retained. Physical Windows 10/11 devices, SmartScreen UX, and machines without WebView2 have not completed acceptance testing.

Windows in-app automatic updates are not enabled yet. Quit the previous version and run the new installer using the existing installation directory to upgrade. Machines without WebView2 need internet access to install the runtime.
