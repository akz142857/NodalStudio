# v0.2.3 — Database programs and dependencies test build

This macOS test build extends PostgreSQL/MySQL schema understanding. It is not a published stable release.

- Adds functions, procedures and triggers to metadata capture, object search and read-only details, preserving PostgreSQL overload signatures.
- Shows catalog-confirmed dependencies and incoming references with navigation to available objects. Dynamic SQL and string routine bodies are not comprehensively analyzed; metadata permissions can limit visibility.
- Adds materialized-view indexes, complete PostgreSQL index definitions, MySQL expression/prefix/descending indexes, and check/unique constraint details.
- Records program and dependency changes in snapshot history, while retaining compatibility with older snapshots. The first capture may show additions caused by expanded metadata coverage rather than recent database DDL.
- Uses shared detail components and English/Simplified Chinese labels, including readable trigger states in history. Opening routine details scrolls the heading below the sticky search field.
- Moves snapshot-capture keychain reads off asynchronous workers so macOS authorization waits do not block local storage/settings work.

Native acceptance used the isolated PostgreSQL 17/MySQL 8.4 fixtures. It covered definitions, permission-limited bodies, dependency navigation, materialized-view/index/constraint details, bilingual UI, 100%/125% scale and a real trigger-state history comparison. The fixture trigger was restored. See `docs/LOCALIZATION_NATIVE_ACCEPTANCE.md` for evidence and validation boundaries.

The test package uses the regular application identifier and data location. No automatic installation or public GitHub Release is included. Notarization is omitted because the earlier automatic approval review rejected uploading the compiled application to Apple. The earlier beta.2 build was stopped and superseded by this user-selected version.
