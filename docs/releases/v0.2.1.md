# Nodal Studio 0.2.1

Nodal Studio 0.2.1 makes available updates easier to notice and reach, while keeping downloads and installation under your control.

## Update reminders

- Startup update checks are enabled by default for new settings. Existing saved preferences, including an explicit opt-out, are preserved.
- A new version appears in a prominent banner below the main toolbar. **View update** opens **Settings > Updates & About** directly.
- **Later** dismisses the banner for the current session. The notification center keeps its own **View update** action.
- Workspace restoration and data-source changes no longer discard an in-flight startup reminder.
- Offline mode, organization policy, update-notification preferences and quiet hours remain respected. If saved settings cannot be loaded, fallback defaults do not trigger an external update check.
- Downloads still require **Download update**. Installation still requires **Install and Restart** and its confirmation dialog.

## Installation

The macOS Universal package supports Apple Silicon and Intel. This release includes a Developer ID-signed and Apple-notarized DMG, the signed updater archive and signature, `latest.json`, and `SHA256SUMS`.

Existing users can open **Settings > Updates & About > Check for updates**. If automatic checks were previously disabled, enable **Automatically check for updates** to receive future startup reminders. The new banner becomes available after installing 0.2.1.

Saved connections, credentials, snapshots, logical relationships, layouts and SQL drafts remain on this device. This patch does not change the local database schema or the production updater signing key. Windows remains an unsigned test distribution with manual installation through its separate CI workflow.

See the [validation record](https://github.com/akz142857/NodalStudio/blob/main/docs/releases/v0.2.1-validation.md) for verification scope and platform limitations.
