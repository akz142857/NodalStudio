# Nodal Studio v1.5.1

## Database switching

- Choose a connection and a database separately in the sidebar. PostgreSQL and MySQL server connections offer a searchable list of databases visible to your account and remember the last database you opened.
- The sidebar names the destination while it opens and initializes. If a switch fails, the current workspace and SQL draft stay available.

## Saved queries

- Open and create saved queries from both Database and Query mode. In Query mode, the saved-query list sits above Database objects and stays available while you search for objects.
- Press **⌘S** on macOS or **Ctrl+S** on Windows to save the active SQL draft. Use the query name in the editor toolbar to rename it.
- SQL drafts stay with their original databases. Deleting the saved query open in the editor retains its SQL as a draft. Schema changes show the target database and SQL in a confirmation dialog.

## Install or update

- The signed and notarized Universal macOS package supports Apple Silicon and Intel. Existing direct-download installations can update through the app.
- To upgrade manually on Windows, quit Nodal Studio and run the x64 installer in the existing installation directory. The installer is unsigned, and SmartScreen or organization policy may restrict installation.
