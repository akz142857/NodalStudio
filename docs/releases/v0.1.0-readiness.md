## Final distribution steps

Build/test logs and the artifact receipt are kept under the ignored
`dist/releases/v0.1.0/` directory. The initial unsigned build validated both
architectures; only the subsequent signed and notarized artifact is eligible for
distribution.

From the repository root, with a clean release commit and completed private config:

```bash
./Scripts/build_macos_release.sh --check
pnpm release:macos
```

The formal script builds Apple Silicon and Intel binaries, signs and notarizes the
application, verifies the app and DMG tickets and Gatekeeper acceptance, and writes
the DMG checksum. Use the resulting artifact under
`target/universal-apple-darwin/release/bundle/dmg/` only after all checks succeed.

Install that final DMG on a test machine and check startup, version, schema loading,
settings persistence, and data preservation. Intel runtime acceptance must be
recorded separately from verifying that the binary contains an Intel slice.

Then create the `v0.1.0` tag on the validated release commit and publish the exact
DMG, its checksum, and the release notes. A locally built candidate or a draft
release is not a published release. Mac App Store submission uses the separate
`pnpm release:macos:appstore` workflow and is outside this website-download candidate.
