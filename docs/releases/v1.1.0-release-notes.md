# Nodal Studio v1.1.0

This release adds read-only SQLite browsing alongside PostgreSQL and MySQL, with a clearer connection dialog and more reliable model-backup restoration.

## SQLite databases

- Open an existing local SQLite database and explore tables, views, triggers, keys, indexes, and relationships without changing the database.
- Capture and compare schema snapshots, including SQLite table options and definitions. Unsupported virtual-table modules retain their definitions and clearly mark unavailable metadata.
- Run read-only SELECT and WITH queries with cancellation, timeouts, result limits, and local query history. Integer values retain their exact representation; binary values are shown as length summaries.
- Export portable model backups without local SQLite file bindings. After restoring a backup, select the database file again to reconnect.
- SQLite AI SQL drafting is not available in this release. Encrypted databases and custom SQLite modules are not supported.

## Connection and backup improvements

- Simplify the connection form, file picker, permission controls, and connection-test feedback.
- Refresh connection lists, settings, and editor state immediately after importing a model backup.
- Preserve PostgreSQL/MySQL connection security settings when switching between those engines.

## macOS installation

The Universal macOS application and DMG are signed with Developer ID and notarized by Apple. The package supports Apple Silicon and Intel Macs. Existing direct-download installations can update through the app using the signed update feed.

## Windows x64 installation and upgrades

The Windows x64 installer is an **unsigned test build** and may trigger SmartScreen or organization policy restrictions. Automatic in-app installation is unavailable on Windows; quit the previous version and run the installer using the existing installation directory.

Clean installation and an in-place upgrade from v1.0.2 are validated on Windows Server 2022 x64 before publication. Physical Windows 10/11 devices, SmartScreen UX, and machines without WebView2 are outside this acceptance scope. Machines without WebView2 need internet access to install the runtime.

## App Store distribution

The Mac App Store package is built separately and retained locally. This GitHub release does not upload or submit an App Store update. App Store installations continue to receive updates through Apple.
