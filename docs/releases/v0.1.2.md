# Nodal Studio 0.1.2

This release fixes DeepSeek responses that could be empty or cut off during AI database understanding.

- Requests to the official DeepSeek HTTPS API now disable thinking mode, preserving the structured answer's token budget. Table explanations, discovery, SQL drafts and provider connection tests share this adaptation.
- A response stopped at its token limit now produces a clear message to shorten the question or reduce the context. Partial answers are rejected and are not automatically retried.
- Other OpenAI-compatible endpoints retain their existing request options.
- Eight synthetic scenarios passed against the real DeepSeek API through the fixed desktop backend, covering table grain, unknown metadata, unsupported statistics, comment instruction boundaries, discovery, ranking and relationship paths. These are structured-answer checks, not a claim of perfect business accuracy.

## Upgrade

On macOS 0.1.1, open **Settings > Updates & About**, check for updates, download, then install and restart. The update is verified with the existing production signing key, and the app backs up its bundle and local SQLite database before installation. Existing connections, snapshots, settings and Keychain credentials are retained. No database schema migration is introduced.

For a manual installation, use `Nodal-Studio_0.1.2_universal.dmg`. Original 0.1.0 users must install the DMG once to enable signed in-app updates. The universal macOS app supports Apple Silicon and Intel, with Developer ID signing and Apple notarization.

The `.app.tar.gz`, `.sig` and `latest.json` assets are used by the updater. `SHA256SUMS` records package checksums. This release contains macOS artifacts only; Windows installation remains manual.
