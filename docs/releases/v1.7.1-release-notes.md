# Nodal Studio v1.7.1

## Code extensions on macOS

- Search Open VSX from **Code → Extensions**, review compatible extensions, and install or update them in the GitHub macOS edition.
- Install the supported **Python Debugger** package from Open VSX to debug local Python files, stop at breakpoints, and inspect stack frames and variables.

## Install or update

- The signed, notarized Universal DMG supports Apple Silicon and Intel. Existing GitHub macOS installations can update in the app.
- Windows users can upgrade manually with the unsigned x64 installer. Quit Nodal Studio before running the installer in the existing installation directory.
