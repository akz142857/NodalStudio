# Nodal Studio v0.2.3 — Windows x64

The Windows distribution uses an NSIS per-user installer with English and Chinese installation interfaces. This is an unsigned test build, identified by `unsigned` in its filename; it is not a signed Windows production package.

## Installation and Updates

- Download `Nodal-Studio_0.2.3_windows-x64-unsigned-setup.exe` and its accompanying `.sha256` file.
- Verify the SHA-256 checksum with PowerShell: `Get-FileHash -Algorithm SHA256 <installer-path>`.
- WebView2 Evergreen is required. If the runtime is missing, the installer downloads it over the internet.
- To upgrade an existing installation, quit the app and run the new installer using the existing installation directory.
- Windows in-app update downloads and installation are not enabled yet. Use the installer on the release page to upgrade. The macOS automatic update flow remains separate.
- SmartScreen or organization policies may block unsigned applications. Acceptance testing did not disable or bypass system security mechanisms.

## Acceptance Scope

The installer was built from source commit `809c50400cf2ec64af1e6a9ce5cc791a90deb51a`, matching the v0.2.3 tag. Acceptance used a real Windows Server 2022 x64 GitHub Actions runner with WebView2 already installed; this does not constitute comprehensive testing on physical Windows 10/11 devices.

The following checks passed:

- [Original installation acceptance](https://github.com/akz142857/NodalStudio/actions/runs/40092100247): clean installation, an installation path containing Chinese characters and spaces, actual WebView2 launch, native IPC, settings and connection persistence across restarts, Windows Credential Manager credential persistence, and uninstallation.
- [In-place upgrade acceptance](https://github.com/akz142857/NodalStudio/actions/runs/40095034816): install the public Windows 0.1.0 package, save settings and a test connection with credentials, close the app, and run the 0.2.3 installer; verify the actual application version and complete binary hash, confirm that settings, connections, and credentials are retained, then uninstall.
- Installer SHA-256: `b3a01bd9358003280fba2f93f53cae7e4dd7e5561d9f3eda240913e313294d75`.

Physical Windows 10/11 devices, the first-download SmartScreen experience, new machines without WebView2, live database connections, and signed automatic updates were outside this verification scope.
