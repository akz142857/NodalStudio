# Nodal Studio v0.2.3 — Windows x64

Windows 分发使用 NSIS 当前用户安装器，支持中文与英文安装界面。安装包为未签名测试版，文件名包含 `unsigned`；它不是已签名的 Windows 正式发行包。

## 安装与更新

- 下载 `Nodal-Studio_0.2.3_windows-x64-unsigned-setup.exe` 及对应 `.sha256` 文件。
- 使用 PowerShell `Get-FileHash -Algorithm SHA256 <安装包路径>` 核对 SHA-256。
- 首次安装需要 WebView2 Evergreen；缺少运行时时，安装器会联网下载。
- 已安装旧版的用户先退出应用，再运行新安装器，在原安装目录完成覆盖升级。
- Windows 应用内自动下载、安装更新尚未启用，使用发布页安装器更新。macOS 的自动更新流程保持独立。
- 未签名程序可能被 SmartScreen 或组织策略拦截。本次验收不包含关闭或绕过系统安全机制。
