# Nodal Studio v1.2.0

## Browse and export PostgreSQL data

- Right-click a table and choose **Open Table** to immediately run a read-only preview of up to 100 rows in Query. You can restore your previous SQL draft after previewing a table.
- Use **Export Wizard** to write selected table columns to CSV or JSON. CSV exports enable spreadsheet formula protection by default.
- Right-click a PostgreSQL schema and choose **Dump SQL File** for **Structure and Data** or **Structure Only**. SQL dumps require a direct connection and an installed `pg_dump` client at least as new as the server. The app streams the dump to disk and protects existing files from being overwritten.

## Faster database navigation

- Expanding a schema or a list of tables, functions, or triggers responds faster while a relationship-heavy model is open.
- Dense relationship lines share a single drawing layer. Zoomed-out table cards show a compact summary and restore field details as you zoom in.
- On Windows, model workspace migration releases its directory handle before removing the old staging directory.

## Install or update

- The signed, notarized Universal macOS build supports Apple Silicon and Intel. Existing direct-download installations can update through the app.
- The Windows x64 installer is an unsigned test build and may trigger SmartScreen or organization policy restrictions. Quit Nodal Studio and run the installer in the existing installation directory for a manual upgrade.
