# Nodal Studio v1.7.2

## Code extensions

- This maintenance release brings the GitHub packages up to date with the latest Code extension changes. The GitHub macOS edition continues to support Open VSX search, installation and updates, alongside the supported Python Debugger.
- The shared source keeps the Mac App Store edition's curated Terraform and TOML syntax catalog separate from the full extension host used by GitHub macOS.

## Install or update

- The signed and notarized Universal macOS installer supports Apple Silicon and Intel. Existing GitHub macOS installations can update in the app.
- Windows users can upgrade manually with the unsigned x64 installer. Quit Nodal Studio before running the installer in the existing installation directory.
