# 交互式离线 HTML Viewer

实现与核对日期：2026-10-14。主界面 **Export offline Viewer** 导出一个自包含 HTML 文件；需要先加载快照及其当前语义。Desktop 复用 HTML 文件保存接口，在 Downloads 中使用唯一文件名，不覆盖已有文件；Web 发起本地下载，仅确认下载开始，无法确认最终保存路径。静态 **Export HTML report** 保留原有行为。

## 导出范围

导出**整个已加载的单快照**，不受 Diagram 搜索、业务域、保存视图、聚焦或当前屏幕可见范围影响。数据库名、方言/版本、采集时间、fingerprint，及已有表/字段、PK/FK、索引、其他约束、视图、枚举详情进入数据字典；能力仍受 PostgreSQL/MySQL 采集器覆盖限制。Web 只能导出已经获得的分享内容，不回查其他来源或未分享对象。

同时包含已加载的**当前**已保存注释、业务域及逻辑关系，语义不冒充采集时的历史版本。排除其他来源/孤立注释、未确认推断候选，不序列化整个快照或工作区 bundle。连接身份、快照本地 ID、域/关系本地 ID、密码、host、查询结果/历史、浏览器设置、布局、云 token、代码路径及备份信息不进入文件。图节点和域使用文件内生成的编号，并以 `(schema, name)` 元组识别表，包含点的引用名称不会合并。

当前只导出捕获快照，不提供 Before/After 比较、删除对象重建、DDL 临时预览导出或持续刷新。App 原始 Diagram 的布局、主题和固定位置不进入 Viewer；需要原图外观时使用 SVG/PNG 导出。

## 阅读与交互

- 搜索匹配表、字段、注释、语义以及对象详情文本；schema / 已有业务域筛选缩小表范围。业务域只含本快照已有成员，视图/枚举不属于表域成员。
- 图和表列表可选择表，显示完整详情入口及可用关系目标；关系导航可以回到目标表。字典中的内部链接会恢复筛选以显示被隐藏的目标。目录与业务域总览仍保留完整导航。
- 一跳关系查看作用于选中表，遵守当前 schema、域、搜索和关系种类筛选；**Show all / reset filters** 返回全图。计数明确显示可见/总表数，不把筛选结果当作导出裁剪。
- 图支持按钮缩放/适配、空白处指针拖动平移；图获得键盘焦点后方向键平移，`+`/`−` 缩放，表卡片 Enter/Space 可选中。视角、选中与筛选仅在内存，重开恢复默认。
- 图中表级物理 FK 用蓝色实线、active 已保存逻辑关系用紫色虚线，箭头为声明 source → target。不推断新关系、不把逻辑关系变为数据库约束。多列 FK 作为一条表级关系，逐列映射在字典中。

图为确定性的网格概览布局，最多四列，不是 App/ELK 排版的复刻。过滤后重新排版和适配；大模型需通过搜索、一跳或缩放阅读。图卡片最多显示 12 个字段，标签最多显示 48 个字符；其余字段、完整名称与属性保留在详情中。平行关系可能重叠，没有复杂避障、节点拖动、连线编辑或关系校验。视图/枚举只提供字典详情，没有图节点。

缺失表/列或不完整映射的物理/active 逻辑关系不画虚构端点，文件明确列出省略关系数，原声明仍在字典。inactive（disabled、orphaned、conflicted、superseded）逻辑关系仅在字典按状态列出。临时图筛选不删除嵌入内容；打印时会显示完整字典详情。

## 只读与限制

文件内只有显示数据、原生 SVG、样式及固定脚本，没有 React/Tauri 运行包、CDN、字体下载、fetch、WebSocket、连接/查询、编辑/写回、AI、云同步、剪贴板、跟踪或 localStorage。不修改在线模型，也没有 HTML 上传、导入或回写入口。脚本采用 SHA-256 CSP 授权，动态数据通过 HTML/JSON 转义和 DOM `textContent` 展示，不执行元数据中的代码；CSP 禁止网络、外部资源、表单、对象及 base URL。

导出限制为 **500 表、5,000 字段、5,000 条物理/active 逻辑关系（含缺失端点声明）、最终文件 32 MiB**。超过上限报告错误，不静默截断或开始保存；可改用静态 HTML 报告。文件内提供范围、只读边界及限制说明。导出等待当前语义完成，防止重复提交，报告运行/结果/错误与同格式重试；来源变更后隐藏旧结果，尚未保存的过期生成不会触发下载。

导出时需 Web Crypto SHA-256 的兼容安全/本机运行端；打开文件不需 Web Crypto、App、数据库或服务器。交互需要现代浏览器、JavaScript 和 SVG；脚本被禁用/阻止时完整静态字典仍可阅读。未承诺所有浏览器版本兼容，也不提供 PDF 或可编辑模型。

文件是可携带的明文元数据，不继承原 Web 分享的访问控制、token 到期或撤销；它不加密、不持续同步、不证明服务器当前状态。交付范围由导出时已加载内容决定。

## 实现与验证

[图数据投影](../apps/frontend/src/reports/offline-viewer-model.ts) 使用独立允许清单，[文件生成](../apps/frontend/src/reports/offline-viewer.ts) 复用静态报告，[独立脚本](../apps/frontend/src/reports/offline-viewer-runtime.ts) 的全部依赖在函数内，导出时序列化为单个 classic script。组件按需加载生成器，复用平台 HTML 保存接口，无新增 Rust/IPC、云契约或依赖。

新增 18 项模型/文件/实际导出脚本、导出组件、App 和能力声明测试，覆盖完整范围、恶意文本、CSP 摘要、身份/隐私字段排除、孤立/外来源对象、缺失与 inactive 关系、脚本禁用回退、MySQL/空模型、大模型/资源上限、搜索/筛选/隐藏链接、关系分类/一跳导航、键盘/指针交互、卡片缩略与完整详情、失败重试/重复提交/来源变更隔离，以及 App 搜索不裁剪导出且不执行查询或语义写入。完整前端 65 文件、384 项测试通过；类型检查、ESLint、生产构建通过。

使用合成 Commerce fixture，从生产压缩模块实际生成 HTML，以仅提供文件的本机静态 HTTP 页面验证独立脚本/CSP、中文语义搜索、关系与一跳导航、重开重置及桌面窗口渲染。浏览器工具禁止 `file://`，未直接实测双击文件打开；没有通过其他方式绕过该限制。文件无外部依赖及静态字典回退另有自动测试证据。未测试原生 Desktop 下载保存或全部浏览器版本；原 HTML 保存/本机下载路径沿用已有验证。
