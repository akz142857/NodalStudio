# SQL 草稿回复语言规则验收

日期：2026-10-25。未提交、上传或发布。

## 实现

查询助手将当前用户消息 currentQuestion 与拼接的历史问题分开传递，同时传入解析后的界面语言 en / zh-CN。后端将语言规则写入系统提示词，并把当前消息作为最后一个独立 JSON 数据块；历史澄清、表注释及语义说明不参与本轮语言选择。

优先级：本轮明确指定语言 → 本轮问题语言 → 无法判断时回退到界面语言。解释、假设和澄清问题统一语言；SQL、JSON 属性名和数据库标识符不翻译。语言偏好不能覆盖只读、证据范围和隐私约束。

对常见明确语言要求及清晰中英文问题进行本地判定；其他语言、否定/引用等复杂表述由模型按当前消息解析。新接口字段可选以兼容旧调用，当前问题限制 2000 字符，界面语言限定枚举。规则不是任意模型的语言输出保证，不自动重试或翻译历史回复。

## 原生验收

当前源码构建的隔离 Nodal Studio Screenshots.app，非 MAS 调试原生包，未替换 /Applications 应用。使用既有 nodalstudio_test 演示库及用户已配置的 DeepSeek；仅生成答案，不执行 SQL，不读取或输出密钥。

首次真实验收发现单纯追加语言提示仍会受历史“用中文回答”影响，因此增加本地判定后重新验收。最终修正版真实调用已通过：

- 英文问题明确要求中文：解释和非空假设列表为中文，SQL 标识符不变（final-chinese.jpg / .ax.txt）。
- 在上述中文回复之后，用英文追问且不指定语言：解释和澄清全部为英文，未沿用历史中文偏好（final-english-followup.jpg / .ax.txt）。

- 中文界面仅输入 `nodalstudio_test.orders`：无自然语言可判断，解释和澄清均回退为中文（final-fallback-zh.jpg / .ax.txt）。验收后已恢复英文界面并清空演示对话。

前端 lint、TypeScript/Vite、Rust/Tauri 打包、cargo fmt 与 git diff --check 通过。SQL 草稿核心 8 项安全测试通过，另有 1 项语言表驱动测试（15 个场景）通过。
