# 本轮复核 P0 补齐：分页、批量已阅、归档恢复

日期：2026-10-25（Asia/Singapore）。本文件记录本地实施与验收，不代表发布或商店验收。

## 实现行为

### 本机后端分页

`get_change_review` / `apply_change_review` 返回有界 `ReviewPage`。支持理解影响、结构变化、处理记录三种视图，以及后端搜索。默认 50 条，上限 100 条；结构与影响待办优先、按标题稳定排序，记录按事件顺序倒序。

游标绑定 sourceId、完整证据 revision、视图、搜索词和页大小；刷新或语义修改后旧游标失效，前端回到第一页并清除选择，未提交说明草稿保留。分页响应始终包含全量待办计数和分类计数，不能通过筛选/翻页绕过完成校验。

分页发生在本机 Rust 后端序列化之前，不是前端拿到全量数据再截断。影响计算与审计重放仍基于一致性全量投影；本次没有将其改为增量物化或 SQL 游标缓存，不宣称减少了全库计算成本。

### 批量结构已阅

用户勾选事项或“选择本页”，预览具体标题后提交。只接受当前 revision 的未处理结构事项，每次 1–100 个唯一 key；当前界面每页最多选 50 个。换页/搜索/证据变化会清空选择。

一个事务保存整批事件，事件记录包含逐项证据。混入业务说明、关系、已处理或不存在事项时整批拒绝；重复 operationId 幂等，审计失败整体回滚。不会创建知识确认，也不会自动推进基线。处理后回到第一页，未处理结构排在前面，便于继续下一批。

### 一键恢复归档

在处理记录选择“恢复归档说明”，预览原文后提交，不需手工复制。只恢复该来源该对象的最新可恢复归档，当前描述必须为空；已有新文本时禁用/拒绝，防止覆盖。兼容前一阶段已存在、没有新事件字段的归档记录。

保留当前标签、负责人等属性；恢复的是原文，不是旧确认资格。后端显式作废旧确认；对象仍缺失时保持不可确认。已完成轮次会重新打开，基线不前移。恢复事件、当前文本、同步队列原子提交；再次恢复同一记录不会重复写入。共享只传普通说明，不携带本机确认。
