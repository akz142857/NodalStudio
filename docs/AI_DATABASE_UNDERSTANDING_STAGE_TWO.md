## 已实现功能

- [x] 桌面应用当前快照的 `Business question` 入口，与普通名称搜索分开；输入不会触发模型请求。
- [x] 在整个已加载快照中检索表名、字段名、允许的数据库注释和业务域名称；可显式限制本地检索域。现有注解不参与召回，等待阶段三的确认依据机制。
- [x] 默认显示 5 个候选、允许查看更多；展示来源、完整限定名、命中字段、直接匹配或扩词假设及具体理由。提供定位、展开关联、进入既有单表解释三个操作。
- [x] 本地常用中英文业务词映射，以及独立的模型辅助扩词；扩词结果需用户主动应用回本地检索。无结果和 account 的登录/财务歧义有明确交互。
- [x] 模型只排序当前发送范围允许的候选；AI 排序单独呈现，其余候选保留本地排序，界面不宣称全库 AI 排序。
- [x] 局部图默认一跳、显式展开两跳；程序从物理 FK 和当前有效的逻辑关系中计算路径，模型只解释已验证路径和建议阅读顺序。
- [x] 路径展示物理/逻辑类别和有序字段映射；未确认推断不参与已知路径。缺失端点、无路径、局部图裁剪均显式提示；引用方向不等于业务执行顺序。
- [x] 临时局部图保留后台完整画布实例、布局、过滤及选择；暂停后台画布快捷键，局部布局不写入完整模型。明确定位/解释操作才改变主视图选择。
- [x] 各 AI 步骤独立预览、独立执行；取消、五分钟过期、重试、设置/来源/快照/根表/域/关系变更和晚到响应均有任务身份隔离。证据定位复用已有字段/约束定位组件，任务切换清理旧证据。

## 交互流程

1. 在桌面应用加载最新快照，点击顶部 **Business question**，输入问题并点击 **Search locally**。
2. 查看本地候选；可调整本地业务域或展开关联。这些操作不调用模型，也不修改 AI 发送设置。
3. 如需扩词，选择 **Question-only term expansion** → **Prepare discovery preview** → 查看实际 JSON → **Send this discovery request** → 主动应用返回词语。
4. 如需候选排序，选择 **Rank permitted candidates**。`OneHop` 要显式根表；`Domain` 要显式选择一个 AI 发送域。本地检索域不会自动成为发送域。
5. 展开候选关联，选择根表、目标表与一/两跳范围。界面先给出本地已知路径；选择 **Explain selected path** 后，再独立预览和执行路径解释。
6. 点击模型回答的证据 ID，在当前任务中查看原始结构并聚焦字段；点击阅读顺序中的已知表可定位到主画布。
7. **Back to previous view** 返回进入前的画布状态；候选的 **Explain this table** 进入阶段一右侧 AI 面板。阶段二不生成或保存注解草稿。

## 实际发送行为

| 操作 | CurrentTable | OneHop | Domain |
|---|---|---|---|
| 本地检索/局部图 | 不联网 | 不联网 | 不联网 |
| 词语扩展 | 仅问题及固定指令 | 同左，根表结构不附带 | 同左，不附带域名称/描述 |
| 候选排序 | 不提供批量排序，保留单表解释入口 | 候选与显式根表一跳白名单取交集 | 候选与显式单域取交集；可无根表，有根表时必须属于该域 |
| 路径解释 | 路径只在本地浏览 | 完整路径每个对象均在根表一跳白名单内才能发送 | 完整路径均在显式域内才能发送 |

实际 HTTP 请求体与预览完全相同。请求中没有自动追加的库名、历史、其他候选、已有回答、注解、逻辑关系自由文本、业务行或连接凭据。注释开关应用到发送证据；排名和路径携带方言。API key 仅用于请求认证，不出现在预览 JSON。

远程禁用/离线策略优先于范围。Web Viewer、DDL 临时模型和历史快照不新增业务 AI 入口；后端也拒绝非最新快照。离线提供方只说明本地能力，不伪造模型排序。

预算：最多向后端提交 100 个本地候选供范围筛选，单次最多 20 张表、1,000 列、2,000 条证据和 128 KiB 上下文，实际 HTTP body 最多 256 KiB。候选裁剪会显示覆盖提示；完整路径越界或超预算直接拒绝，不拆成多个请求。局部图最多 100 张表，优先保留选定路径并显示省略数量；此本地上限不扩大远程预算。
