# 统一操作反馈

本轮统一评估路线内的操作反馈：Diagram SVG/PNG 导出、HTML 数据字典、批量业务域成员、布局保存与排版、结构预检及其本地理由、快照刷新、比较快照详情加载。复用现有操作和通知入口，不增加持久审计、遥测、自动重试或数据库写入。

## 展示约定

所有接入操作使用 `OperationFeedback` 展示以下状态：

| 状态 | 展示与交互 |
|---|---|
| Running | 正在执行的操作摘要；标记忙碌，运行期间不显示重试或关闭结果 |
| Completed | 实际结果摘要：目标文件/下载发起、对象数量、图像尺寸、保存范围等 |
| Failed | 失败摘要与默认展开的 Error details；可重试的操作显示具体重试按钮 |
| Information | 能力/数据覆盖说明，例如 Web 分享没有历史快照；不显示无法实现的重试 |

运行和成功使用可访问的 `status`，失败使用 `alert`；标识具体操作、提供键盘焦点样式，支持深浅主题。错误文本按普通文字渲染。结果可选 Result details；支持关闭结果的操作只允许关闭终态，关闭不撤销操作。

Completed 表示应用已完成该步骤：Web 导出只确认下载已发起，不能证明用户最终保存了文件；结构预检只确认计算完成，不保证数据库完整合法。临时布局明确只对当前视图生效，不显示全图保存成功。

## 重试行为

| 操作 | 重试含义 |
|---|---|
| Diagram export | 保留失败的 SVG/PNG 格式，重新捕获当前图形并导出 |
| HTML report export | 使用当前已加载快照和语义重新生成报告；语义未就绪时禁用 |
| Domain update | 重新校验当前选择和目标业务域，加入尚未存在的成员；不能重复写入正在保存的同一个域 |
| Layout save | 保存当前完整位置/尺寸/固定状态，继续使用原串行队列，保留可见布局和撤销历史 |
| Arrangement | 重试对应的全图、选中表自动布局或对齐命令，使用当前可编辑表集合；临时视图不写完整布局 |
| Preflight | 重新计算当前快照和启用选项，不刷新数据库 |
| Review notes | 保存失败重试会话中的当前理由；加载失败只重读本地存储，不重跑结构检查 |
| Snapshot refresh | 再次刷新当前来源，失败时保持已加载快照；成功显示表数、变更数和是否产生新快照 |
| Before/After load | 分别重取对应历史快照；Web 未包含的历史明确标为信息，不调用历史接口 |

重试由用户触发，开始时清除旧成功或错误。导出、业务域和刷新通过统一 `useOperation` 阻止同一范围的重复提交；布局保留原有版本检查和串行保存，避免破坏连续排版、撤销及批量写入规则。

## 范围与过期结果

`useOperation` 将操作与当前来源/快照/图形/选择范围绑定，切换范围立即隐藏旧结果；晚到的成功和失败、卸载后的完成回调都不能覆盖当前反馈。返回之前的范围也不会自动恢复过期结果。刷新额外检查当前来源，旧来源的响应不能替换新来源快照。

这不是底层取消机制：已经发送的保存或导出请求可能继续完成，不能因关闭面板或切换范围就声称文件/语义写入被撤销。重试不会回放旧视图数据。批量业务域仍保留服务层的同域写入保护。

反馈显示在操作所在位置；刷新结果在顶部，报告结果在报告入口，Diagram 导出结果在画布右下方并限制高度、可滚动。图形导出有结果时，左侧选择工具保留独立可滚动空间。

本轮不改造已有 Query、AI、Cloud、Git 和 Settings 专用任务流程；它们后续可复用此组件与状态规则。自动连接失败继续进入已有通知，并说明从数据源重新连接。本轮没有扩展数据库方言能力或分享数据契约。

## 验证

新增 18 项组件、Hook、真实 React Flow 和 App 测试；覆盖重复提交、非 Error 错误、明确重试、失败后成功、当前格式/当前数据、来源和选择切换、晚到响应、卸载、React StrictMode、错误文本转义、临时布局和理由加载重试。原有布局保存队列、比较详情、导出和预检测试同步验证统一展示。

完整前端测试共 296 项；生产构建、类型检查和 ESLint 一并验证。实际浏览器使用合成元数据和模拟导出回执验证运行/失败/重试/成功，不写真实导出文件。
