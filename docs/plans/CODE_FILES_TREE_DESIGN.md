# Nodal Studio Code 文件树设计

本设计补充 [Code View 开发计划](CODE_VIEW_DEVELOPMENT_PLAN.md)。文件树服务于本地只读审阅。用户能顺着目录找到 AI 改动，也能浏览与改动相关的上下文。

## 1. 紧凑目录

当一个目录只包含一个可显示的子目录时，将两级合并为一行。继续检查下一级，直到遇到文件、多个子目录、空目录或无法可靠读取的目录。该规则适用于任意语言和目录名称。参考 [VS Code Compact Folders](https://code.visualstudio.com/updates/v1_41#_compact-folders-in-explorer)。

```text
flow-erp-web
└── src
    ├── main
    └── test
        ├── java / com / wahool / erp / web
        │   ├── feign
        │   │   └── OrderReviewTest.java
        │   └── gateway
        └── resources
```

`test` 有两个子目录，因此单独显示。`web` 是合并行的末级。展开合并行时直接列出 `web` 的子项。树中用一行展示这段路径，文件标签页、面包屑、Quick Open 和审阅记录继续使用完整的项目相对路径。

## 2. 浏览与审阅规则

| 操作或状态 | 行为 |
| --- | --- |
| 展开、折叠 | 点击合并行切换。状态按真实路径记录。关闭紧凑模式时，已打开的链可以逐层展开显示。 |
| 键盘 | 上下键按可见行移动，Home 和 End 到首末行。右键展开或移到第一项，左键折叠或回到父行，Enter 打开文件或切换目录。 |
| 窄栏 | 优先给末级名称留空间。前缀按可用宽度省略，悬停显示完整路径，辅助技术读取完整的合并行名称。 |
| 隐藏项 | 「显示隐藏文件」决定点文件和点目录是否参与合并。`.git` 仍由原生层排除。 |
| 空目录 | 展开后保留目录行，下面留空。加载、读取错误和受限列表仍有对应提示。 |
| 变更标记 | `Changes` 提供文件状态。文件行显示变更类型，包含改动的折叠目录和合并行仍显示标记。 |
| 已删除项 | 从变更清单补齐已消失的文件及祖先目录。位于合并链侧面的删除项会阻止该层合并，并可直接打开 Diff。 |
| 设置 | 「紧凑目录」默认开启。用户可从 Files 底部切换，偏好保存在本机。 |

打开仍在工作区的文件进入 Source。已删除的文件从 Diff 查看。比较基准、审阅备注及文件的 Git 状态由现有 Code 工作区管理。

## 3. 数据与职责

原生层返回当前目录的一层 `entries`。`path` 是受授权根目录约束的真实相对路径。`compactSegments` 是可选的子目录名称数组，供前端组合展示。路径和名称分开，前端无需从显示文字还原路径。

1. 原生层对当前列表中的目录做有限探查，生成可合并的物理路径。探查使用已有的目录句柄与逐级无跟随链接读取，复用路径验证。
2. 前端将目录结果与同一份 `Changes` 合并。沿合并链检查可见的历史分支或删除文件，并在遇到这些兄弟项时提前截断。
3. 行的身份和折叠入口保留首段真实路径。展开时按末级路径发起目录请求，并将链中的真实路径记为已展开，方便切换显示模式。

目录查询按项目、相对路径和紧凑策略缓存。打开新的合并行只查询末级的一层。手动刷新使目录查询失效，同时重新读取工作区变更。目录合并属于展示规则，可以随磁盘结构、隐藏项设置和变更清单重新计算。

## 4. 性能与异常

- 一个原生目录列表最多进行 256 步补充探查。一行最多再合并 16 个子目录，仍受现有路径深度限制。额度耗尽的位置保留普通目录，可继续展开。关闭紧凑模式后省略补充探查。
- 读取异常、未知条目和符号链接会停止对应链的合并。打开目录失败或列表受限时沿用文件树的状态提示。缺失目录中的变更仍可通过历史路径访问。
- 目录操作通过本地只读接口。切换项目时为新项目建立目录查询、选中文件及展开状态。紧凑模式偏好跨项目保存。

## 5. 验收

| 用例 | 验收结果 |
| --- | --- |
| `src/test/java/com/wahool/erp/web` 连续单子目录 | 展开 `test` 后显示一行 `java / com / wahool / erp / web`，同级 `resources` 仍可见。 |
| 展开合并行并打开 Java 文件 | 直接请求末级目录，编辑器和变更清单使用完整相对路径。 |
| 链中新增普通兄弟文件或显示隐藏项 | 刷新或切换后在该层停止合并，兄弟文件仍可访问。 |
| 链中有从磁盘消失的兄弟文件 | 合并停止，删除项带状态，可进入 Diff。 |
| 关闭紧凑模式 | 真实目录逐级显示，已打开的文件及当前选择保留。 |
| 键盘经过合并行 | 展开后可移到首个子项，左键能从子项回到合并行。 |
| 探查额度耗尽或目录不可读 | 从仍可读的位置继续导航，错误和受限状态可见。 |
