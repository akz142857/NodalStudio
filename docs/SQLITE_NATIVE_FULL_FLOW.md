## 实测发现并修复

便携备份导入会正确移除 SQLite 文件绑定，但前端设置页的数据源列表与左侧连接切换器各自缓存 profile，导入后仍显示旧路径；连接编辑器也可能继承旧路径。后端会拒绝无绑定的刷新，重启后界面才与实际状态一致。

修复：导入成功后同时刷新数据源和知识/设置；主应用通知连接面板重新读取 profile，忽略已失效的异步列表响应。设置页重命名、复制、移除连接也复用此通知。最终原生包再次完成“已绑定 → 导入备份 → 不重启打开设置/切换器/编辑器”，确认三处立即更新，文件字段为空；随后重新绑定并执行查询成功。

补充了 App 导入后路径清除回归（修复前明确失败）以及连接切换器/编辑器同步回归。同时清理两处先前 SQLite 测试中的 ESLint 错误，不改变运行时行为。
